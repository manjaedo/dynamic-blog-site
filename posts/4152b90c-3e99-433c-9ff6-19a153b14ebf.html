CSS 다크 모드, 변수 하나로 시작하기

CSS 변수만으로 라이트/다크 테마를 전환하는 방법을 단계별로 소개합니다.

2026.10.17 1분 읽기

다크 모드는 색상을 전부 반대로 바꾸는 작업이 아닙니다. 배경과 글자, 테두리 같은 의미 단위를 변수로 만들고, 테마에 따라 값만 바꾸면 됩니다.

의미 있는 이름을 쓰기

--gray-100 대신 --bg, --fg, --card처럼 역할을 기준으로 이름을 붙입니다.

Code 
:root {
  --bg: #fbf7ef;
  --fg: #101014;
  --card: #ffffff;
}

[data-theme="dark"] {
  --bg: #101016;
  --fg: #f7f1e6;
  --card: #191926;
}

시스템 설정과 사용자 선택

처음에는 prefers-color-scheme을 따르고, 사용자가 토글을 누르면 그 선택을 저장합니다. 저장된 값이 있으면 시스템 설정보다 우선합니다.

  • 테마 상태는 data-theme 속성으로 관리
  • 색상은 전부 CSS 변수로 참조
  • 이미지와 강조색의 대비도 함께 확인

이렇게 해 두면 나중에 색을 바꿀 때도 변수 값만 수정하면 됩니다.
